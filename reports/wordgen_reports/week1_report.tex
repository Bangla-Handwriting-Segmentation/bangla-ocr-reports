\section{Code Fixes Applied}

\subsection{S\_long Data Loading (14 min to 1 sec)}

File: wordgen/round3/s\_long\_train.py

Issue: filter\_train\_writers() used iterrows() on 90k rows

Fix: Vectorized with pandas isin() and boolean masking

Impact: 1400 times speedup

\subsection{E\_sel SupConLoss Gradient}

File: wordgen/round3/e\_sel\_train.py

Issue: Zero-loss returned scalar without grad\_fn

Fix: Changed to (z.sum() * 0.0) to preserve gradient

Impact: Backpropagation chain preserved on empty batches

\subsection{VAE Channel Mismatch}

Files: b0\_style\_pipeline\_null.py, c1\_pen\_pipeline\_null.py

Issue: VAE expects 3-channel RGB but received 1-channel grayscale

Fix: Stack grayscale 3 times, decode output averaged back to 1-channel

Impact: Pipeline correctly handles channel conversion

\subsection{B3 Text Encoder Context}

File: b3\_mid\_t\_contrastive.py

Issue: Empty dict passed to text encoder expecting tokenizer output

Fix: Build context from tokenizer output with proper shapes

Status: Text encoder fix verified
